# 保険ドキュメント特化型 AI チャットボット

PDF を知識源として、保険に関する質問へ根拠付きで回答する RAG アプリケーション。

## 特徴

- **HyDE 検索**: 仮想回答を生成してから検索し、精度を向上
- **引用表示**: 回答の根拠（文書名・ページ番号）を明示
- **質問分類**: 保険関連 / 挨拶 / 無関係を自動判定し、適切に処理
- **セキュリティ**: XSS 対策、セッション管理、設定の外部化
- **コーポレートデザイン**: ネイビー + ディープグリーン + ウォームストーンのトラスト指向パレット（Claude Design で生成・適用）

**技術**: FastAPI, LangChain, OpenAI API (GPT-4o-mini), FAISS

## UI / Design System

フロントエンドは **Claude Design demo** の成果物を取り込んでおり、以下の要素で構成される。

- `保険AIチャット Design System/` — Anthropic の [Claude Design](https://claude.ai/design)（Opus 4.7 搭載）で生成したデザインシステム。トークン (`colors_and_type.css`)、React UI キット、プレビュー、ブランドマークを含む
- `static/design-tokens.css` — 上記デザインシステムのトークンを本体プロジェクトに取り込んだもの（色・タイポ・余白・角丸・シャドウ・モーション）
- `static/style.css` — トークン変数のみで書かれたアプリケーション側のスタイル。Tailwind CDN への依存を撤廃
- `static/script.js` — `/chat` が未接続のときはモック応答（`CANNED`）にフォールバックするため、バックエンドを起動しなくても UI の挙動を確認できる

### デザイン方針のポイント

| | 旧 UI | 新 UI (Claude Design) |
|---|---|---|
| カラー | 青一色 (#3b82f6) + 灰 | ネイビー (#16375f) + ディープグリーン + ゴールド少量 + ウォームストーン |
| タイポ | Noto Sans JP のみ | 見出し Noto Serif JP、本文 Noto Sans JP、ページ番号 IBM Plex Mono |
| 形状 | 12px 角丸、グラデ吹き出し | 4–10px 角丸、文書的フラット、AI バブルは上辺ネイビー 1px |
| アクセント | 青塗り送信ボタンのみ | ゴールドの引用元ページ番号バッジ (1 箇所のみ) |

### UI だけを確認する（バックエンド不要）

```bash
# リポジトリのルートで
open static/index.html
```

ブラウザに直接 index.html を開くと、質問例チップからモック応答 + 引用元パネルの挙動まで確認できる。

## セットアップ

```bash
# 1. リポジトリのクローン
git clone https://github.com/kbobshida/insurance-ai-chatbot.git
cd insurance-ai-chatbot

# 2. 仮想環境の作成
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\Activate

# 3. 依存パッケージのインストール
pip install -r requirements.txt

# 4. 環境変数の設定
# ルートディレクトリに .env ファイルを作成し、以下を記入
```

`.env` ファイルの内容:
```env
# 必須: OpenAI API キー
OPENAI_API_KEY="sk-your-actual-api-key-here"
# OpenMP の警告を回避
KMP_DUPLICATE_LIB_OK=TRUE

# オプション: LangSmith を使う場合のみ
# LANGCHAIN_TRACING_V2="true"
# LANGCHAIN_API_KEY="ls__..."
# LANGCHAIN_PROJECT="保険相談AIチャット"

# オプション: カスタマイズする場合のみ（デフォルト値があります）
# MAX_SESSIONS=1000
# SESSION_TIMEOUT_HOURS=24
# RATE_LIMIT_PER_MINUTE=10
```

**最低限必要な設定は `OPENAI_API_KEY` のみです。** その他の設定は `config.py` のデフォルト値が使用されます。

```bash
# 5. PDFを配置
mkdir -p docs
# docs/ に PDF ファイルをコピー

# 6. ベクトルストアを生成
python ingest.py

# 7. サーバーを起動
uvicorn server:app --reload --port 8000
```

ブラウザで `http://127.0.0.1:8000` にアクセス


オプション設定は `config.py` のデフォルト値を使用

## 既知の課題

### パフォーマンス
- **1質問あたり LLM 4回呼び出し、15-25秒**
  1. 質問分類（必須）
  2. HyDE検索（精度向上）
  3. 回答生成（必須）
  4. エージェント整形（冗長）
- エージェント層削除で25%高速化可能だが、拡張性のため保持

### データソース
- **PDF のみ**: ユーザー固有の契約情報や外部データ取得不可
- プロアクティブな提案には追加のデータソースが必要

### スケーラビリティ
- メモリ内セッション（再起動で消失）
- ローカルFAISS（本番環境には Pinecone等が必要）
- 単一サーバー構成

**注意**: 開発段階。本番環境では認証、HTTPS、監視等の追加実装が必要。

## トラブルシューティング

| 問題 | 解決方法 |
|------|---------|
| `faiss_index` が見つからない | `python ingest.py` を実行 |
| OpenAI API エラー | `.env` の API キーを確認 |
| OpenMP エラー (macOS) | `KMP_DUPLICATE_LIB_OK=TRUE` を設定 |
